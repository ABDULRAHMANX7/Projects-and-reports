* **Programming:** C/C++, Python, PyTorch

## 📂 Projects Included

### 1. Integrated Circuit CAD (Cadence Virtuoso)
*   **Description:** Design, simulation, and physical layout of a hierarchical CMOS digital circuit using 45nm technology.
*   **Key Tasks:**
    *   Schematic and Symbol creation for Inverter and NAND gates.
    *   Physical Layout design (Metal1, Metal2, Poly routing).
    *   Successfully passed **DRC** (Design Rule Check) and **LVS** (Layout vs. Schematic) with zero errors.

### 2. Analog IC Design and Principles (LTspice)
*   **Description:** Simulation and characterization of CMOS transistors, CMOS inverters, and combinational logic gates.
*   **Key Tasks:** 
    *   DC and Transient analysis (VTC curves, Propagation Delay).
    *   Energy-Delay trade-off and Leakage analysis.
    *   Technology scaling effects (65nm to 32nm).

### 3. Machine Learning Research Project | Skoltech (SMILES-2025)
*   **Description:** Fine-tuned a compact 1B-parameter LLM to simplify complex financial and regulatory texts while preserving critical information. Conducted as part of the SMILES-2025 program at Skoltech.
*   **Key Tasks:**
    *   Implemented Unsupervised Style Transfer (UST) and Parameter-Efficient Fine-Tuning (PEFT).
    *   Adapted the training pipeline for Neural Processing Unit (NPU) environments and resolved hardware/dependency conflicts.
    *   Developed a data validation pipeline to fix critical data integrity issues and restored model generation.
    *   Evaluated model performance using custom NLP metrics (AlinaEstimator and ARIEstimator).
